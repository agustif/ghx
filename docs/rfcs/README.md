## Lifecycle

- Draft: useful enough to discuss, not accepted.
- Accepted: chosen direction, ready to decompose into issues.
- Implementing: work is active and linked to subissues.
- Shipped: accepted behavior exists in `ghx` with validation.
- Superseded: replaced by a newer RFC or ADR.
